# StoreAPI

ASP.NET Core Web API for managing products and categories.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- LINQ
- Dependency Injection
- DTOs and validation
- Migrations

## Features

- Product CRUD
- Category CRUD
- Product-category relationship
- Data validation
- SQL Server persistence
- API testing with Bruno

## API endpoints

- GET /api/products
- GET /api/products/{id}
- POST /api/products
- PUT /api/products/{id}
- DELETE /api/products/{id}
- GET /api/categories
- GET /api/categories/{id}
- POST /api/categories
- DELETE /api/categories/{id}
